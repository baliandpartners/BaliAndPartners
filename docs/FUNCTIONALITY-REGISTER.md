# Functionality register

The machine-readable inventory is generated by `node scripts/audit.mjs <base-url> <output-directory>`. It records visible anchors, buttons, inputs, selects, summaries and tabs on every page at desktop/mobile widths, including expanded menus, specimen stages, prepared enquiry drafts and clipboard fallback controls. Local audit output: `/workspace/bali-audit/final/audit.json`. External reachability remains separately qualified below.
